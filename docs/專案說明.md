# 專案說明

## 1. 專案概述

**MyDraw 繪圖板**（以下簡稱 MyDraw）是一套以 Windows 為主的原生繪圖應用程式，使用 WinUI 3、Win2D 與 .NET 10 開發。專案定位為「快速啟動、低干擾、適合課堂與日常筆記」的輕量繪圖工具，而不是完整的專業繪圖軟體。

本專案最早依 `docs/功能規劃.md` 的構想開始，逐步加入多筆刷、多圖層、專案存讀、PNG 匯出、自動復原、檔案關聯與多語系等功能。截至 **0.14.2**，已具備可日常使用的基本繪圖與檔案工作流程。

- 版本：0.14.2
- 命名空間：`Com.StudentTools.MyDraw`
- 授權：MIT License（Copyright (c) 2026 mark216tw）
- 儲存庫：<https://github.com/mark216tw/win-mydraw-01>

## 2. 專案目標

1. **快速開始**：開啟後立即取得可用畫布，不經過專案精靈或登入流程。
2. **直覺操作**：常用筆刷、顏色、筆刷設定與圖層集中在單一工具列與彈出面板。
3. **低延遲手寫**：支援滑鼠、觸控與手寫筆，包含壓感、傾斜與筆尾橡皮擦。
4. **畫布最大化**：工具列可收合、可切換左右，並提供沉浸模式與全螢幕。
5. **資料安全**：自動復原、儲存備份與原子寫入，降低當機或誤關閉造成的損失。
6. **可維護性**：以 MVVM 與服務拆分商業邏輯，搭配單元測試與 UI 驗證腳本。

## 3. 目標使用者

- 需要在課堂或會議中快速做手寫筆記的學生與上班族。
- 使用 Windows 平板、觸控筆電或繪圖板，希望有輕量手寫工具的使用者。
- 想了解 WinUI 3 + Win2D 繪圖應用架構的開發者。

## 4. 功能範圍

### 4.1 已提供

- 筆刷：鋼筆、鉛筆、原子筆、馬克筆、螢光筆、書法筆、噴槍、蠟筆、橡皮擦、平移。
- 筆刷參數：粗細、不透明度、柔和度、流量、噴槍模式、壓力曲線、壓感開關。
- 顏色：20 色常用色票與自訂調色盤。
- 最愛畫筆：儲存、套用、重新命名、刪除、排序。
- 圖層：新增、選取、重新命名、顯示、鎖定、透明度、移動、刪除。
- 畫布：縮放、平移、格線、尺寸調整、預設尺寸、沉浸模式、全螢幕。
- 檔案：`.mydraw` 專案開啟／儲存／另存、最近開啟、`.bak` 備份、PNG 匯出。
- 復原／重做：筆畫新增、圖層新增／刪除／排序。
- 自動復原：30 秒快照、啟動復原提示、7 天清理。
- 系統整合：單一實例、`.mydraw` 檔案關聯、命令列開檔。
- 外觀與在地化：淺色／深色／跟隨系統、5 種色彩主題、繁體中文與英文。

### 4.2 非目標（目前不包含）

- 專業級濾鏡、圖層混合模式、遮罩與向量路徑編輯。
- 雲端同步、帳號系統、協作與線上分享。
- PDF、JPG、SVG 等其他匯出格式。
- 外掛系統或腳本自動化。
- 完整行動版或跨平台版本。

## 5. 名詞定義

| 名詞 | 說明 |
| --- | --- |
| 筆畫（Stroke） | 一次 pointer 按下到放開之間產生的連續筆跡資料。 |
| 圖層（Layer） | 獨立顯示透明度、可見性與鎖定狀態的筆畫集合。 |
| 筆刷預設（Preset） | 每種工具的預設尺寸、不透明度、壓感與材質參數。 |
| 最愛畫筆（Favorite Brush） | 使用者儲存的工具＋顏色＋筆刷參數快照。 |
| `.mydraw` | MyDraw 的可編輯專案檔，實際上是一個 ZIP 容器。 |
| 復原快照（Recovery Snapshot） | 執行期間定期寫入的暫存專案，用於異常結束後復原。 |
| 圖塊（Tile） | 圖層渲染快取使用的 512 × 512 像素單位。 |
| 沉浸模式 | 隱藏頂部與工具列、只保留畫布的模式。 |
