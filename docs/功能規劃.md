# Windows 學生繪圖軟體規格與架構規劃書
**專案定位**：專為國、高中學生設計之輕量、高效、好上手的 Windows 原生繪圖工具  
**核心精神**：零學習曲線、直覺易懂、畫布極大化、現代原生效能

---

## 1. 系統技術選型與架構

| 項目 | 選用技術 | 技術優勢與採用理由 |
| :--- | :--- | :--- |
| **開發平台** | **.NET 10 (C#)** | 微軟最新高效能運行環境，記憶體管理與運算效能最佳化。 |
| **使用者介面 (UI)** | **WinUI 3 (Windows App SDK)** | Windows 原生現代介面，支援 Fluent Design（Mica/Acrylic 材質、深淺主題），符合 Windows 系統原生風格。 |
| **繪圖渲染引擎** | **Win2D (Direct2D 硬體加速)** | 高效能 GPU 渲染，原生支援多圖層合成、透明度混合、濾鏡及高幀率畫布平移縮放。 |
| **手寫/數位筆整合** | **Windows Pointer API / DirectInk** | 原生支援低延遲筆跡、多階壓感、傾角感應與硬體防手掌誤觸。 |

## 2. 介面佈局與操作體驗 (UI/UX)

為了讓學生能專注創作，介面設計維持「**畫布面積最大化**」與「**功能平鋪不深藏**」兩大原則：

```
+-------------------------------------------------------------------------+
| [復原] [重做] | 畫布比例 (100%) | 智慧輔助 (格線/幾何) | [儲存/匯出]      | <- 頂部超薄狀態列
+---+---------------------------------------------------------------+-----+
| 筆|                                                               | 圖層|
| 刷|                                                               | [+] |
| --|                                                               |-----|
| 橡|                                                               | [3] |
| 皮|                                                               | [2] |
| --|                      中央極致大畫布                           | [1] |
| 選|                                                               | 底圖|
| 取|                                                               |-----|
| --|                                                               | 顏色|
| 形|                                                               | 色票|
| 狀|                                                               | 環狀|
+---+---------------------------------------------------------------+-----+
```

1. **左側精簡工具列（寬度約 48px）**：
   * 垂直圖示排列，點擊筆刷即於旁側彈出小型調節滑桿（筆刷粗細、不透明度），不常駐佔用空間。
2. **右側收納面板（寬度約 180~200px）**：
   * **上半部：圖層面板**（縮圖、能見度眼睛開關、圖層鎖定、透明度滑桿）。
   * **下半部：色彩選擇區**（16 色大色塊常用色票 + 微軟原生色輪選擇器）。
3. **頂部輕量導航列（高度約 36px）**：
   * 復原 (Ctrl+Z)、重做 (Ctrl+Y)、畫布縮放比例、輔助格線切換、儲存與匯出。
4. **全螢幕沉浸模式**：
   * 支援 `F11` 或 `Tab` 鍵一鍵隱藏兩側面板，使畫布填滿螢幕。

## 3. 核心功能規格

### A. 畫布與圖像匯入/匯出
* **畫布範本**：內建學生常用規格（1920×1080 螢幕比例、A4 列印比例、方形社群比例、自訂解析度）。
* **直接貼上圖片**：支援 `Ctrl + V` 直接將剪貼簿圖片貼入畫布，自動新增為獨立圖層，並提供變形控制框（移動、旋轉、等比例縮放）。
* **拖曳載入**：支援直接從檔案總管將 PNG、JPG、WEBP 圖片拖曳至畫布。
* **專案儲存與匯出**：
  * **專案格式**：支援多圖層保留的自訂專案檔（ZIP 打包結構：JSON 描述檔 + 點陣圖資料）。
  * **快速匯出**：支援 PNG（透明背景可選）、JPG、PDF（作業繳交便利格式）。

### B. 筆刷與繪圖工具
避免過度專業繁複的參數，保留學生最實用的 5 大筆刷：
1. **鋼筆 / 鉛筆**：線條俐落、支援筆壓，適合線稿與筆記。
2. **馬克筆 / 彩色筆**：支援半透明疊色與色彩混合，適合塗色插畫。
3. **螢光筆**：Windows 筆記專用半透明筆刷，疊加於文字與底圖時不遮蓋黑色墨水。
4. **油漆桶**：支援封閉區域快速填色與邊緣容差值調整。
5. **橡皮擦**：
   * *筆跡擦除*：整筆筆劃一鍵清除（筆記模式）。
   * *像素擦除*：標準點陣圖橡皮擦（支援大小調節）。

### C. 多圖層系統 (Layer Management)
* **圖層操作**：新增、刪除、複製、向下合併、拖曳重排圖層順序。
* **狀態控制**：顯示/隱藏切換、圖層鎖定（防止誤觸塗抹）。
* **透明度控制**：0% 至 100% 拖曳調節。
* **精選混色模式 (Blend Modes)**：
  * **正常 (Normal)**
  * **色彩增值 (Multiply)**（線稿下方上色必備）
  * **濾色 (Screen)**（光暈與高光效果）
  * **覆蓋 (Overlay)**（對比與氛圍調整）

## 4. 數位板與手寫筆 (Pen Tablet / Stylus) 支援規格

針對 Wacom、Huion、XP-Pen、Surface Pen 等各大品牌數位板與手寫筆進行原生最佳化：

### A. 原生通訊協議 (Windows Pointer API)
* **壓感階數支援**：支援 2048 至 8192 階硬體筆壓感應。
* **傾角感應 (Tilt)**：支援 `XTilt` 與 `YTilt`，馬克筆與鉛筆可依傾斜角度改變塗抹筆觸寬度。
* **硬體筆尾擦除**：透過 `PointerPointProperties.IsEraser` 辨識筆尾，倒轉筆尖即可自動切換至橡皮擦。

### B. 筆壓曲線與動態開關
* **動態感應勾選**：
  * *筆刷尺寸感應*：下筆越重線條越粗。
  * *筆刷不透明度感應*：下筆越重色彩越濃郁。
* **筆壓校正曲線（簡易 3 點式）**：
  * *偏軟 (Soft)*：輕壓即可達到最大筆幅（適合力道較輕的學生）。
  * *標準 (Linear)*：線性對應。
  * *偏硬 (Hard)*：避免下手過重導致線條忽粗忽細。

### C. 按鍵自訂與防誤觸
* **筆身按鍵自訂**：
  * *第一側鍵（下鍵）*：滴管取色 / 暫時切換橡皮擦。
  * *第二側鍵（上鍵）*：復原 (Ctrl+Z) / 畫布平移 (Pan)。
* **硬體防手掌誤觸 (Palm Rejection)**：
  * 偵測到數位筆懸浮（Hovering）時，自動封鎖螢幕單指繪畫，僅允許雙指縮放平移。

## 5. 學生專屬學習與應用場景功能

1. **智慧幾何圖形辨識 (Ink to Shape)**：
   * 學生隨手畫出圓形、方形、三角形或箭頭，長按筆尖 0.5 秒即可自動校正為標準向量圖形（理化、幾何作圖必備）。
2. **多模式輔助格線**：
   * 提供「方格紙（筆記/幾何）」、「透視輔助線（美術課透視法）」與「漫畫分鏡框」，匯出時可一鍵隱藏。
3. **作業/考卷截圖標註模式**：
   * 貼上考卷或講義截圖時，系統自動鎖定底圖為背景層，筆畫自動繪製於新圖層，橡皮擦不會擦除考卷題目。
4. **防手震平滑曲線 (Stroke Smoothing)**：
   * 即時過濾滑鼠或低階數位板的抖動，讓線條保持圓滑流暢。
5. **和諧色彩推薦提示**：
   * 在調色盤中提供基礎對比色、相鄰色標記，輔助美術課作業的色彩搭配。

## 6. 核心架構程式實作參考 (C# / WinUI 3)

### 數位筆與壓感事件監聽架構
```csharp
using Microsoft.UI.Input;
using Microsoft.UI.Xaml.Input;
using Windows.Foundation;

private void Canvas_PointerMoved(object sender, PointerRoutedEventArgs e)
{
    PointerPoint pt = e.GetCurrentPoint(canvasControl);

    // 檢查輸入設備是否為手寫筆/數位板
    if (pt.PointerDeviceType == PointerDeviceType.Pen)
    {
        // 1. 取得硬體壓感 (0.0f ~ 1.0f)
        float rawPressure = pt.Properties.Pressure;
        float adjustedPressure = ApplyPressureCurve(rawPressure);

        // 2. 判斷是否為筆尾橡皮擦硬體翻轉
        bool isEraser = pt.Properties.IsEraser;

        // 3. 取得筆身傾斜角度
        float tiltX = pt.Properties.XTilt;
        float tiltY = pt.Properties.YTilt;

        // 4. 動態計算筆刷粗細與不透明度
        float dynamicSize = baseBrushSize * (useSizeDynamics ? adjustedPressure : 1.0f);
        float dynamicOpacity = baseOpacity * (useOpacityDynamics ? adjustedPressure : 1.0f);

        // 5. 派送至渲染引擎
        drawingEngine.AddStrokePoint(pt.Position, dynamicSize, dynamicOpacity, isEraser, tiltX, tiltY);
    }
    else
    {
        // 滑鼠或觸控繪製邏輯
        drawingEngine.AddStrokePoint(pt.Position, baseBrushSize, baseOpacity, false, 0, 0);
    }
}

// 簡易筆壓校正曲線計算
private float ApplyPressureCurve(float pressure)
{
    return pressureCurveType switch
    {
        PressureType.Soft => MathF.Sqrt(pressure),          // 偏軟：低力度即有明顯筆幅
        PressureType.Hard => MathF.Pow(pressure, 2.0f),      // 偏硬：需要較大力度才能達到滿值
        _ => pressure                                       // 線性預設
    };
}
```

## 7. 開發里程碑建議

* **階段一：MVP 核心建立**
  * WinUI 3 + Win2D 基礎視窗。
  * 支援單圖層畫布之平移、縮放 (Zoom/Pan)。
  * 支援基本滑鼠與筆刷繪製。
* **階段二：圖層與圖像處理**
  * 實作多圖層架構與透明度混合模式。
  * 實作 `Ctrl + V` 貼上外部圖像與矩形選取變形框。
* **階段三：數位板驅動深度整合**
  * 整合 Windows Pointer API 壓感、傾角與筆尾橡皮擦。
  * 實作筆壓設定面板與防手震平滑演算法。
* **階段四：學生學習場景工具**
  * 整合圖形辨識 (Ink to Shape)、底圖格線範本、PDF 作業格式匯出。
