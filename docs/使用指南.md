# 使用指南

本文件說明 MyDraw 0.14.2 的安裝、介面操作、工具使用、檔案管理與疑難排解。若想了解內部設計，請見 [系統架構與技術文件](系統架構與技術文件.md)。

## 1. 安裝與啟動

### 1.1 使用 GitHub Releases

1. 前往 <https://github.com/mark216tw/win-mydraw-01/releases>。
2. 依系統架構下載：
   - `MyDraw-0.14.2-win-x64.zip`（多數 Intel／AMD 電腦）
   - `MyDraw-0.14.2-win-arm64.zip`（Windows on ARM，例如 Snapdragon X 系列）
3. 解壓縮到任意可寫入的資料夾。
4. 安裝必要執行階段：
   - [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（依架構選擇 x64 或 arm64）
   - [Windows App SDK 1.8 Runtime](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)（依架構選擇 x64 或 arm64）
5. 執行 `MyDraw.exe`。

> Release zip 為 framework-dependent（non-self-contained），不會附帶 .NET 與 Windows App SDK Runtime，因此必須先安裝上述執行階段。

### 1.2 從原始碼執行

```powershell
git clone https://github.com/mark216tw/win-mydraw-01.git
cd win-mydraw-01
dotnet build MyDraw.sln -c Debug -p:Platform=x64
dotnet run --project src\MyDraw\MyDraw.csproj -c Debug -p:Platform=x64
```

### 1.3 Windows SmartScreen

目前發行檔未做程式碼簽章。若 Windows 顯示「已保護您的電腦」或 SmartScreen 警告，請先確認檔案來自本專案 Releases，再選擇「仍要執行」。

## 2. 第一次啟動

- 預設會建立 **1080 × 1080** 的空白畫布，並自動縮放至適合視窗大小。
- 若上次程式異常結束或關閉時有未儲存變更，啟動時可能出現「復原」對話框：
  - **復原**：載入上次的自動復原快照。
  - **捨棄**：刪除該快照並建立新畫布。
- 復原快照預設保留 7 天，逾時會自動清理。

## 3. 介面導覽

```text
┌─────────────────────────────────────────────────────────────┐
│ 檔案  編輯  畫布  檢視  設定        [目前工具] [畫布尺寸] [縮放] │
├────┬────────────────────────────────────────────────────────┤
│復原│                                                        │
│重做│                                                        │
│畫筆│                     繪圖畫布                            │
│…   │                                                        │
└────┴────────────────────────────────────────────────────────┘
```

- **頂部選單列**：檔案、編輯、畫布、檢視、設定。
- **狀態區**：顯示目前工具、畫布尺寸與縮放比例；點擊尺寸可開啟畫布設定，點擊縮放可重設為 100%。
- **工具列**：復原／重做、常用筆刷、更多畫筆、橡皮擦、最愛畫筆、平移、筆刷設定、顏色、圖層。
- **畫布**：Win2D 繪圖區，支援滑鼠、觸控與手寫筆。
- **浮動提示**：底部會顯示畫布操作提示。

工具列可透過「設定 → 外觀設定 → 繪圖工具列位置」切換左側或右側，設定會保留。

## 4. 繪圖工具

### 4.1 工具清單

| 工具 | 特性 |
| --- | --- |
| 鋼筆（Pen） | 平滑、具壓力與速度感，適合線稿。 |
| 鉛筆（Pencil） | 有材質顆粒感，支援壓感與不透明度壓感。 |
| 原子筆（Ballpoint） | 固定粗細、邊緣俐落，適合快速筆記；預設工具。 |
| 馬克筆（Marker） | 較粗、半透明，適合標題與重點。 |
| 螢光筆（Highlighter） | 扁平半透明筆尖，重疊不累積加深。 |
| 書法筆（Calligraphy） | 依筆尖方向與傾斜改變寬度。 |
| 噴槍（Airbrush） | 霧狀或顆粒噴濺，可調柔和度與流量。 |
| 蠟筆（Crayon） | 粗糙材質與隨機顆粒。 |
| 橡皮擦（Eraser） | 支援羽化柔和度與平滑邊緣；手寫筆筆尾橡皮擦會自動切換。 |
| 平移（Pan） | 拖曳移動畫布，不產生筆畫。 |

### 4.2 筆刷設定

點擊工具列的「筆刷設定」可調整：

- **粗細**：1–80。
- **不透明度**：5%–100%。
- **柔和度**：0–100%（依工具顯示）。
- **流量**：5%–100%（依工具顯示）。
- **噴槍模式**：霧狀（Mist）或顆粒（Grain）。
- **壓力曲線**：柔和、線性、銳利。
- **使用壓力控制尺寸／不透明度**：需搭配支援壓感的裝置。

每支筆刷的設定會分開記住，重新啟動後仍會保留。

### 4.3 顏色與最愛畫筆

- 點擊「顏色」面板可使用 20 色常用色票，或透過自訂調色盤選色。
- 點擊最愛畫筆面板的「儲存目前畫筆」，可將目前工具、顏色與筆刷設定存成具名最愛。
- 最愛畫筆支援套用、重新命名、刪除與上／下移排序。

## 5. 圖層

點擊工具列的「圖層」開啟面板：

- **新增圖層**：建立新圖層並置於最上層。
- **選取圖層**：點擊清單項目切換目前繪圖圖層。
- **重新命名**：在名稱欄位直接編輯。
- **顯示／鎖定**：勾選或取消勾選。鎖定或隱藏的圖層無法繪圖。
- **透明度**：拖曳滑桿調整 0%–100%。
- **上移／下移**：調整圖層順序。
- **刪除**：需二次確認，至少保留一個圖層。

> 新增、刪除與排序支援復原；改名、透明度、顯示與鎖定目前不納入復原。

## 6. 畫布操作

| 操作 | 方式 |
| --- | --- |
| 繪圖 | 滑鼠左鍵、觸控或筆尖 |
| 平移 | 滑鼠右鍵拖曳、按住 `Space` 拖曳、或選擇平移工具（`H`） |
| 縮放 | 滑鼠滾輪、`Ctrl+` `+`／`Ctrl+` `-` |
| 重設縮放 | `Ctrl+0` 或點擊狀態區的縮放比例 |
| 格線 | `Ctrl+G` 或「檢視 → 顯示格線」 |
| 沉浸模式 | `Tab`（隱藏頂部與工具列） |
| 全螢幕 | `F11`；`Esc` 離開 |
| 畫布尺寸 | `Ctrl+Alt+C` 或點擊狀態區的尺寸按鈕 |

畫布尺寸支援 64–8192 像素，並提供 1080×1080、1920×1080、A4 直式、A4 橫式與自訂大小。縮小畫布前會顯示裁切提醒。

## 7. 專案檔案

### 7.1 新增、開啟、儲存

- `Ctrl+N`：新增空白畫布（有未儲存變更時會詢問）。
- `Ctrl+O`：開啟 `.mydraw` 專案。
- `Ctrl+S`：儲存目前專案；若尚未命名會開啟儲存對話框。
- `Ctrl+Shift+S`：另存新檔。
- **最近開啟**：檔案選單可快速開啟最近 10 個專案，也可清除紀錄。

### 7.2 `.mydraw` 格式

`.mydraw` 是可編輯專案檔，實際上是一個 ZIP 容器，內含 `manifest.json` 與 `document.json`。格式細節見 [系統架構與技術文件](系統架構與技術文件.md#8-mydraw-專案格式)。

### 7.3 備份與復原

- 儲存既有專案時，會先將舊檔保留為 `<檔名>.mydraw.bak`。
- 程式每 30 秒自動寫入復原快照；關閉時若有未儲存變更，也會先寫入最後快照。
- 復原快照位於 `%LOCALAPPDATA%\MyDraw\Recovery\`。

## 8. PNG 匯出

- 使用 `Ctrl+E` 或「檔案 → 匯出 PNG」。
- 匯出期間會顯示進度，可取消；取消時會刪除未完成的檔案。
- 匯出內容會依圖層可見性與透明度合成，畫布外的筆畫會被裁切。

## 9. 外觀與設定

「設定 → 外觀設定」可調整：

- **顯示模式**：跟隨系統、淺色、深色。
- **色彩主題**：護眼黃（預設）、海洋藍、森林綠、薰衣草紫、中性灰。
- **繪圖工具列位置**：左側或右側。

「設定 → 檔案關聯設定」可建立或移除 `.mydraw` 與 MyDraw 的關聯。關聯寫入目前使用者的 `HKCU\Software\Classes`，不需要系統管理員權限。

## 11. 疑難排解

### 啟動時顯示缺少 .NET 或 Windows App SDK

請安裝與系統架構相符的 **.NET 10 Desktop Runtime** 與 **Windows App SDK 1.8 Runtime**。arm64 系統需安裝 arm64 版本。

### 程式無法開啟或閃退

1. 確認 Windows 版本為 10.0.17763 以上。
2. 查看 `%LOCALAPPDATA%\MyDraw\logs\crash-YYYYMMDD.log`。
3. 嘗試暫時移開 `%LOCALAPPDATA%\MyDraw\settings.json` 與 `Recovery` 資料夾後重新啟動。

### 啟動時一直出現復原提示

復原快照可能來自先前的測試或異常結束。可選擇「捨棄」，或手動刪除 `%LOCALAPPDATA%\MyDraw\Recovery\` 下的檔案。

### 繪圖延遲或卡頓

- 確認使用 GPU 驅動程式正常的顯示卡。
- 超大畫布（超過約 1200 萬像素）會降低渲染 DPI 以維持效能。
- 關閉其他高負載程式後再試。

### 手寫筆壓感無效

- 確認裝置與驅動程式支援壓感。
- 在「筆刷設定」確認已勾選「使用壓力控制尺寸」或「使用壓力控制不透明度」。
- 滑鼠不提供壓感，會以固定壓力 1.0 繪圖。

### 無法開啟 `.mydraw`

- 確認檔案格式版本未被更新版本變更（目前格式版本 6）。
- 若檔案損毀，可嘗試 `<檔名>.mydraw.bak` 備份。

## 12. 本機資料位置

| 資料 | 路徑 |
| --- | --- |
| 設定檔 | `%LOCALAPPDATA%\MyDraw\settings.json` |
| 損毀設定隔離檔 | `%LOCALAPPDATA%\MyDraw\settings.json.corrupt` |
| 復原快照 | `%LOCALAPPDATA%\MyDraw\Recovery\*.mydraw`、`*.json` |
| 當機記錄 | `%LOCALAPPDATA%\MyDraw\logs\crash-YYYYMMDD.log` |
| 專案備份 | 與專案同目錄的 `<檔名>.mydraw.bak` |

MyDraw 不會上傳任何本機資料，也沒有遙測或網路同步功能。
