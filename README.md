# MyDraw繪圖板

MyDraw 是依照 `docs/功能規劃.md` 開發的 Windows 原生學生繪圖工具，著重快速啟動、直覺筆刷與最大化畫布空間。

## 已完成功能

- WinUI 3 頂部系統選單 + 可選左／右側的一站式集中工具列 + Win2D GPU 極大化畫布
- 鉛筆、原子筆、螢光筆常駐第一層，馬克筆、噴槍、鋼筆、蠟筆、書法筆收納於「更多畫筆」第二層選單
- 噴槍支援霧狀／顆粒模式、柔和度、流量與固定弧長密度；蠟筆與鉛筆具備材質顆粒；螢光筆重疊不累積加深；橡皮擦支援羽化柔和度與平滑邊緣
- 10 款高辨識度專屬幾何向量工具圖示（含斜頭螢光筆、噴嘴霧點噴槍、十字四向箭頭平移）
- 滑鼠、觸控及手寫筆輸入，支援手寫筆壓感、筆尾橡皮擦與連續曲線平滑筆跡
- 第二層彈出面板（`Flyout`）：筆刷粗細／不透明度／柔和度／流量、噴槍模式、壓力曲線、壓感設定、20 色色票與自訂調色盤、多圖層管理
- 多圖層新增、選取、重新命名、刪除、上下移動、顯示、鎖定與透明度
- 復原、重做、方格輔助線、畫布縮放與平移（支援空白鍵臨時拖曳平移，平移時顯示手掌游標）
- 預設 1080×1080 方形畫紙，另有 1920×1080、A4 直／橫式及自訂大小，縮小前提供非破壞性裁切安全確認
- 每支筆刷分開記住粗細、不透明度、柔和度、流量、噴槍模式、壓力曲線與壓感設定，重新啟動後仍保留
- 可將目前畫筆的種類、顏色、粗細、不透明度與壓感設定儲存為具名最愛，支援套用、重新命名、刪除及上／下移排序
- 新增空白畫紙、`.mydraw` 可編輯專案開啟／儲存／另存新檔與 PNG 匯出
- `Tab` 沉浸模式與 `F11` 全螢幕模式
- 跟隨系統、淺色與深色顯示模式，以及黃色護眼、海洋藍、森林綠、薰衣草紫、中性灰主題
- 視窗大小、位置及外觀設定記憶，支援 Per-Monitor V2 DPI 與多解析度 App 圖示
- 同一筆自我交叉不再產生白洞，已選畫筆滑鼠移入時維持底色
- 畫布游標顯示目前筆刷大小與筆尖形狀（含書法筆斜向筆尖、螢光筆扁平筆尖），方便掌握落筆範圍
- 設定選單提供「檔案關聯設定」，可建立或移除 `.mydraw` 與 MyDraw 的關聯
- 設定選單末尾提供「關於」，可查看版本、授權與隱私資訊
- 常用 20 色色票在滑鼠移入時顯示高亮外框與縮放回饋
- 開啟程式或新增畫紙時，畫布會自動縮放至適合視窗並置中
- 已完成按需建立的圖層點陣圖塊快取，完成筆畫不再於每個畫面重播，連續繪製多筆仍保持跟手

## 系統需求

- Windows 10 1809 或更新版本，x64
- .NET 10 SDK（開發建置）
- Visual Studio 2026 或可建置 WinUI 3 的對應工具（IDE 開發）

## 建置與執行

```powershell
dotnet restore MyDraw.sln
dotnet build MyDraw.sln -c Debug -p:Platform=x64
dotnet run --project src/MyDraw/MyDraw.csproj -c Debug -p:Platform=x64
```

## 快捷鍵與操作方式

- 滑鼠左鍵或筆尖：繪圖
- 滑鼠右鍵、按住 `Space`（空白鍵）拖曳或平移工具 (`H`)：移動畫布
- 滑鼠滾輪、`Ctrl++` / `Ctrl+-` / `Ctrl+0`：縮放畫布與重設為 100%
- `P` / `M` / `E` / `H`：快速切換鋼筆 / 螢光筆 / 橡皮擦 / 平移
- `[` / `]`：快速增減筆刷粗細
- `Ctrl+N`：新增空白畫紙
- `Ctrl+O`：開啟 `.mydraw` 專案
- `Ctrl+S` / `Ctrl+Shift+S`：儲存 / 另存 `.mydraw` 專案
- `Ctrl+E`：匯出 PNG 圖片
- `Ctrl+Z` / `Ctrl+Y`：復原 / 重做
- `Ctrl+Alt+C`：變更畫紙大小
- `Ctrl+G`：顯示或隱藏輔助格線
- `Ctrl+,`：外觀與色彩主題設定
- `Tab` / `F11`：切換沉浸模式 / 全螢幕模式
- `Esc`：離開全螢幕（對話框開啟時優先關閉對話框）
- 設定 → 外觀設定 → 繪圖工具列位置：選擇左側或右側，重新啟動後保留
